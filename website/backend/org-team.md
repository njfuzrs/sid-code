# 组织与团队

这页写给**管理员**：怎么建组织和团队，以及它们在策略、预算、插件市场里起什么作用。

组织和团队本身不管任何东西。它们是**层**：策略和预算按「设备 > 团队 > 组织」求值，插件市场按组织或团队限定可见范围。没有团队，团队层的配置就没有对象。

## 联动：配了之后员工那边会怎样

| 你在管理台做了什么 | sid-code 什么时候知道 | 拉取失败时 | 员工看到什么 |
| --- | --- | --- | --- |
| 新建组织 / 团队 | 不影响任何设备。新团队里没有设备 | —— | 无 |
| 改名称 | 只改显示名，ID 不变，所有引用照旧 | —— | 无 |
| 把设备分进团队（「设备」页「调整归属」） | 服务端下一次请求就按新团队求值；客户端要等下一次拉取策略、预算 | 按各通道自己的规则（见[概览](/backend/#员工端和后端之间的通道)） | 团队层的策略和预算开始对它生效 |

## 在管理台里操作

页面在左侧菜单「**组织与团队**」。页面顶部的说明写着「飞书登录的新设备默认落在登录组织、不在任何团队」，这是本页最重要的一句。

### 新建组织

1. 「组织」区块点「**新建组织**」。
2. 「组织 ID」填 `acme`；「名称」可选，默认同 ID；「理由」必填。
3. 确定，提示「已保存」。

一家公司通常一个组织就够了。飞书登录的设备会自动落进 `CTL_LOGIN_ORG_ID`（默认 `default`）指定的组织，这个组织不存在时会自动创建。想让员工直接进 `acme`，把 `CTL_LOGIN_ORG_ID` 改成 `acme`，见[部署与配置](/backend/deploy#控制面)。

### 新建团队

1. 在组织那一行点「**新建团队**」，或在「团队」区块点「**新建团队**」后选「所属组织」。
2. 「团队 ID」填 `platform`；「名称」可选；「理由」必填。
3. 确定。

团队 ID 只要求在**同一组织内**唯一：`acme/platform` 和 `other/platform` 是两个不同的团队。

### 改名

「操作」列的「**改名**」。只能改显示名称，「名称」和「理由」都必填。

### 把设备分进团队

在这一页做不了。到「[设备](/backend/devices#调整归属)」页，在设备行点「调整归属」。

没有「用户默认团队」：同一个人的每台新设备都要单独分。没有批量分配。

### 变更审计

页面底部「**变更审计（最近 100 条）**」列出新建组织、组织改名、新建团队、团队改名、调整设备归属、吊销设备、签发注册码这几类操作，列为「时间 / 动作 / 对象 / 变更 / 理由 / 操作者」。审计和变更在同一个事务里写入，不会出现「改了但没记」。

## 字段说明

| 字段 | 取值 | 校验规则 | 作用 |
| --- | --- | --- | --- |
| 组织 ID | 字母或数字开头，只能含字母、数字、`.` `_` `-`，最长 128 | 重复 409。**建好后不能改** | 被策略、预算、市场条目、注册码引用 |
| 团队 ID | 同上 | 同组织下重复 409；所属组织不存在 404。**建好后不能改** | 同上 |
| 名称 | 任意文本 | 新建时可选，改名时必填 | 只用于显示 |
| 理由 | 任意文本 | 改名、新建团队必填 | 进审计 |

ID 格式只在管理台这一页校验。通过[签发注册码](/backend/devices#签发)或注册码兑换时的 `--team` 间接建出来的组织和团队不受这个格式约束，见那一页的警告。

## 状态码

| 状态码 | 原因 |
| --- | --- |
| 404 | 新建团队时所属组织不存在；改名时对象不存在 |
| 409 | 组织 ID 已存在；团队 ID 在该组织下已存在 |
| 422 | 理由为空；ID 格式不对或超长 |

策略、预算、市场在写入时也会检查它们引用的组织或团队，不存在一律 404。所以要**先建团队，再配团队层**。

## 能力边界（如实说）

**1. 不能删除，不能改 ID。** 建错了的组织和团队只能留着、改个名字标注「废弃」。所以建之前想好 ID。

**2. 飞书登录的设备默认不在团队。** 团队层策略和预算对它们不生效，直到你手工调整归属。没有按飞书部门自动分组。

**3. 团队不嵌套。** 只有组织 → 团队两级，一台设备同时只属于一个团队。

**4. 团队不是权限边界。** 管理员能看到所有组织、所有团队的数据，不能把管理权限限定在某个团队。

## 常见问题

### 建了团队、配了团队层策略，但没有一台设备命中

团队里还没有设备。「团队」表的「设备数」是 0 就是这个原因。到「设备」页把设备分进来。

### 想按飞书部门自动建团队

目前不支持。可以按部门手工建团队，再逐台调整设备归属。

### 用 `default` 组织还是新建一个

都可以。只有一个组织时用 `default` 最省事；名字在意的话，新建 `acme` 并把 `CTL_LOGIN_ORG_ID` 改成它，再把已经在 `default` 里的设备调整过去。
