# 新底座卸载时补上 fd 1 兜底序列，字节与顺序逐个对齐旧底座（B9 / T7.1b，契约 X3）

## 决定了什么

规则全部来自对 legacy 的黑盒探针（24 个卸载变体，没读旧代码，D-5）。改动在 `packages/tui/src/`：

- `ink.tsx` 卸载顺序改为：① 经 stdout 写同步包裹的显示光标，**只在最后一帧动态区非空时写**（`lastOutputHeight > 0`）；
  ② 新增 `writeExitFallback()`，**同步 `writeSync(1)`**：退 alt（`<AlternateScreen>` 挂着时）→ 关鼠标跟踪（无条件）
  → drain stdin → `>4m <u ?1004l ?2004l` → `?25h` → 清 OSC 9;4 进度 → 清 tab 状态（`SID_DISABLE_TAB_STATUS` 时不写）；
  ③ 然后才是 React 清理。原先 I4 再关一次、进度 / tab 清除写在 `finishUnmount` 里（React 清理**之后**、经 stdout），
  这三处都挪进了兜底段。非 TTY 照旧只写同步包裹的一个换行。
- `AlternateScreen.tsx`：卸载期间的关鼠标 + `?1049l` 交给实例 `deferUntilUnmounted()`，React 清理跑完再写。
  legacy 里它排在 raw mode 释放那几条之后，当场写会排到前面。
- `App.tsx`：经 `registerInputControl` 多传一个 `isStopped`（Ctrl+Z 挂起中）。兜底段在挂起中不 drain stdin
  （否则 I4 / I7「挂起期间卸载不碰 stdin」会红），字节照写。

契约：`packages/cli/tests/render-port/unmount.test.tsx` 21 条 + 夹具 `fixtures/unmount-app.tsx`（子进程，fd 1 原样即结果，
`<W>` 标出经流写的块）。每条先断言 legacy 等于写死的字节，再断言 next 与 legacy 相同。SPEC X3 按实测改写。

## 放弃了什么（以及为什么不选）

- **按设计文档原写法「卸载最后再写一遍兜底」**：放弃。实测 legacy 的兜底段在 React 清理**之前**，raw mode 释放写的
  那几条是重复写入。放在最后，信号退出路径一样能用，但正常卸载的字节顺序对不上 S12 / L4。
- **兜底段走 `options.stdout`**：放弃。legacy 直写 fd 1，render 到别的 TTY 流时兜底仍落在 fd 1（`pt` 变体钉住）。
  这是兜底的意义：流对象坏了、进程正在退出时仍能还原终端。
- **用 `lastOutput !== ''` 判末帧是否为空**：放弃。主屏出帧路径上 `lastOutput` 恒为空串（只有非 TTY / 读屏路径写它），
  第一版就因此把有内容的 23 个变体全弄红了；`lastOutputHeight` 才是两条路径都维护的字段。

## 拿什么证明它生效了

- **找到这条规则的过程**：render-port 在 next 上一开始就是 431/431、term-bench 16/16 全绿，S12 并不红。
  基线比的是网格 / 模式 / 字节数（1.1 倍容差），**分辨不出顺序**。所以直接对拍了卸载字节：12 个变体全部 DIFF。
- `unmount.test.tsx` 双底座 21/21。变异自证 8 处全红：去掉兜底（12 红）、兜底不退 alt（6）、光标与进度换序（12）、
  尾段改走 stdout（12）、挂起中仍 drain（1）、alt 退出不推迟（6）、忽略 `SID_DISABLE_TAB_STATUS`（1）、
  显示光标不看末帧（3）。
- **夹具测试台漏掉的那条，是 L4 PTY 抓出来的**：`expect` 在真实 PTY 里起 `sid-code`，等到输入框后按两次 Ctrl+C 退出。
  第一轮两底座的退出尾巴差一个 `?2026h ?25h ?2026l`；调用栈归因定位到 CLI 退出前 `isQuitting` 那一帧擦空了动态区。
  夹具在 `NODE_ENV=test`（同步出帧）下复现不了，所以那几条用例改在生产调度下跑。修完后 PTY 退出段的转义序列两底座逐个一致。
- render-port + tui 双底座 1376/1376；`lint`、`format:check`、`lint:boundary`、`tui:spec`（64 / 62）、`tui:similarity`、
  `tui:surface --check`、`docs:gen-reference --check` 都通过；`tsc` 87，与基线相同；`make build` 通过、无 undefined 警告。
- 全量双跑结果见设计文档 T7.1b 完成段。
