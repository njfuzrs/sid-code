# 自定义 Agent 支持模型档位与最大轮次默认值

## 决定了什么

为 Markdown 自定义 Agent 与插件 Agent 接通 `modelTier` / `maxTurns` frontmatter：解析时校验字段、注册时传入动态 `AgentDefinition`；`modelTier` 沿用既有档位映射与模型优先级，Agent 定义的 `maxTurns` 作为默认上限，调用级正数优先。CLI `--agents` 内联定义也提供相同的两个字段和输入校验。未提供 `maxTurns` 时仍无上限，不引入隐式轮次限制。

## 放弃了什么（以及为什么不选）

- 只删除/收窄用户文档字段：不能满足 Agent 级成本档位与轮次控制需求；保留现有动态 Agent 与模型 registry 的实现模式即可。
- 把 Agent 定义存在可复用 `SubAgent` 实例的共享状态：同一实例可能承载并发任务，保存调用专属定义会有串用风险；执行路径从 Agent 类型动态解析定义，并将默认轮次与调用级上限在执行函数内合并。
- 将无效 `maxTurns` 静默归一为无限：正好掩盖“本想设置上限但没生效”的错误；解析层 warn 并忽略无效配置，resolver 保留已有调用级非正数语义。
