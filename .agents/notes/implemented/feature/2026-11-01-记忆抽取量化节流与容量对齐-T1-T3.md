# 记忆抽取：逐条读计数 + 按调用方计成本 + 节流影子 + 截断态禁止后台新建

## 决定了什么

落地《记忆写入与召回横向剖析》第五部分 T1–T3：

- **T1.1 读计数**：`memory/read-stats.ts`，Read 成功读到 project/global 记忆条目时，在记忆目录下的旁路文件 `.read-stats.json` 里累加 `{lastRead, readCount}`（键 = 相对路径）。MEMORY.md 和 team scope 不计。
- **T1.2 按调用方计成本**：`telemetry/agent-usage.ts`，在 `recordBilledRequest` 去重之后按 `agentId` 聚合，账本行加 `byAgent` 表。会话 jsonl 落 `agent_usage` 元数据，resume 时回灌为基线；SessionStart 只清本进程，/clear 全清（与 side-call-sink N12 同构）。
- **T1.3**：`scripts/memory-report.ts` 只读报告，输出每个目录的「条数 / 进索引 / 读过 ≥1 / 30 天未读」，以及 `fork:memory-extract` 近 7 天的请求数、token 和成本。
- **T2 节流**：新增 `memoryExtractInterval`（settings）/ `SID_CODE_MEMORY_EXTRACT_INTERVAL`（env），缺省 1。每个 end_turn 发一条 `memory_extract` 事件（ran / skipped{interval|in_flight|main_wrote}、seq、written、tokens），用作影子数据。`drainPending` 收尾时如有节流积压，补跑一次（`catch_up`）。
- **T3 容量**：提取 prompt 头部给出「索引已用 X/200 条、Y/25KB；已截断」，清单按 `INDEX_TYPE_RANK` 排序（该常量移到 `index-budget.ts`，作为唯一事实源）。截断态下后台代理的 `save_memory` 新 key 和 `write` 新建记忆文件都会被拒，记 `memory_guard{index_full}` 与 `denyKind: index_full`。已有 key、edit 不受限，主模型路径不受限。

## 放弃了什么（以及为什么不选）

- **方案原文的「frontmatter 回写 last_read / read_count」**：否决，原因有三点，都已回源码核实。
  ① `FileReadTracker` 按 mtime + 内容判定「读后被改」，Read 完立刻改写文件，会让模型随后对同一条记忆的 edit 被拒；`utimes` 保 mtime 不可靠，mtimeMs 是亚毫秒浮点。
  ② `MemoryStore.set` → `serializeMemoryFile` 只写 5 个已知字段，记忆每更新一次计数就归零，报告会系统性低估。
  ③ scan/recall 的新鲜度按 mtime 算（方案 §四 已点出）。
  旁路文件不是 `.md`，`enumerateMemoryFiles` 和团队同步都不会碰到它。
- **账本加单个 `agentId` 字段**：否决。账本是每会话一行 upsert，一行里混着多个调用方；拆成多行会让 `aggregateEntries` 的 sessions 计数翻倍。改为 `byAgent` 表。
- **把 `index_full` 并进 `scope_denied`**：否决。它不是越权，混进去之后越权曲线就读不准了。
- **在途跳过（in_flight）也记积压、收尾补跑**：否决。interval=1 时这会改变现有行为（多跑一次 fork）；方案只要求给节流兜底。
- **本 PR 改节流默认值**：方案要求先跑两周影子数据，默认值改动另提 PR。

- 变异自证 4 条：去掉节流判据（3 fail）、去掉收尾补跑（2 fail）、截断态不拒（2 fail）、write 绕过（1 fail），均能打红，已还原。
- 本机真跑 `bun scripts/memory-report.ts`：sid-code 项目 201 条记忆只有 64 条进索引，与剖析结论同量级。读计数和 byAgent 要等新版本跑一周才会有数。
- 上线后的验收口径（方案原文）：报告能给出「从未被读」条数；`byAgent["fork:memory-extract"]` 可按会话加总；`memory_index_health.orphan_count` 两周不再增长；`index_full` 计数非零且主模型写入不受影响。
