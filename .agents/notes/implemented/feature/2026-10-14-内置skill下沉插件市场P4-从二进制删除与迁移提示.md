# 内置 skill 下沉插件市场 P4：从二进制删除 7 项，加旧命令迁移提示

## 决定了什么

- **从二进制删掉 7 项**（方案 §3.1）。P3 已经在生产两个市场跑通、锁定企业的镜像也上架了，删除的前置条件满足：
  - builtin 迁移项：`ci-self-heal`、`code-governance`、`incident-rca`、`security-audit`。它们已在 `plugins/ops`、`plugins/compliance` 里。删除前逐个 `diff -rq` 核对过，两边只差改名、路径和自我描述这几处预期改动，插件副本是完整的。
  - builtin 删除项：`bug-fix`。
  - bundled：`commit-push-pr`（删除）、`pr-comments`（迁到 `plugins/github-pr`）。
  - A 类剩 3 个（code-review / skill-creator / claude-code-migration），B 类剩 6 个（simplify / verify / commit / review / pr-workflow / pr）。
- **旧命令迁移提示**（`packages/cli/src/command/migrated-skills.ts`，方案 §7）：
  - 挂在 `CommandExecutor.executeSlashCommand` 的「命令表查不到」分支，放在「未知命令」之前。用户或项目自己定义了同名 skill 时，命令表能查到，用的还是他们自己的那个。
  - 文案分两种，判据与 `/plugin install` 用同一个 `evaluatePluginOrigin`：官方市场可装 → `/plugin install <插件>@sid-code，之后用 /<插件>:<skill>`；锁定且官方被拒，或 `officialMarketplace:false` → 「请联系管理员在企业市场上架 <插件>」。
  - 删除项说明替代做法：commit-push-pr → `/commit` + `git push` + `/pr` 或 `/pr-workflow`；bug-fix → 直接描述 bug。
  - 表保留 180 天，到 `2027-04-12` 为止。期限写在源文件头注释里，单测读这一行，过期就红。
- **TUI 补全回车的劫持**：实测发现，敲 `/commit-push-pr` 回车时，补全列表的「回车直接执行补全项」会把它模糊匹配成 `/commit`，**直接执行一次提交**，迁移提示根本出不来。改为：整条输入是迁移表里的旧命令、而补全项是别的命令时，提交原文（`InputArea.tsx` + `isMigratedSkillInput`）。
- 同步改掉指向已删命令的措辞：`bash.ts` 工具描述、`commit.ts` / `pr.ts` 的 prompt、`git-attribution.ts` 注释（顺带写清「读归因配置的必须是 TS skill」）、`tool.ts` / `registry.ts` / `ask-user-question.ts` / `app.ts` / `cli.ts` 的注释。
- 测试：
  - `bundled.test.ts` 改成 6 个，并反向断言 commit-push-pr、pr-comments **不在**；
  - `git-attribution.test.ts` 的 PR 路径去掉 commit-push-pr；
  - `allowed-tools-fork-semantics.test.ts` 的只读护栏改为指向插件副本——迁成插件不该让只读 skill 悄悄拿到 edit/write。
- 文档：`website/extend/skills.md` 改成「3 个内置 + 官方插件市场」两张表，附锁定企业的白名单写法；`website/use/worktree.md` 去掉 `/commit-push-pr`。
- 补上方案 §9 要求、P1–P3 都没写的 `rejected/` Note（六个否决项）。

## 放弃了什么（以及为什么不选）

- **迁移提示直接转调新命令**（敲 `/security-audit` 就自动跑 `/compliance:security-audit`）：插件没装时转不了；装了就等于为旧名做了短名回退，正是 rejected 里否决的那件事。
- **用「未知命令」加一条通用提示代替这张表**：用户需要知道的是装哪个插件、装完叫什么。通用提示给不出这两样，锁定企业还会拿到一条装不上的命令。
- **在运行时按日期自动停用这张表**：运行时依赖本机时钟，到期那天用户会看到行为突变却没人知道为什么。改成单测到期红、由人删代码，删除是一次可 review 的改动。
- **把期限、`isOfficialMarketInstallable` 导出给测试用**：`command-system-gate` 会把只有测试引用的导出判为死导出（实测 30 → 32 被拦）。测试改为通过真实 executor 入口的输出断言分支，期限从源码注释里读。
- **修 TUI 补全「模糊匹配回车直接执行」这个通用行为**（比如只有前缀精确命中才直接执行）：这是补全的整体交互，影响所有命令，超出 P4 范围。这里只堵住旧命令名这一种会造成误执行的情况。
- **改博客里提到旧命令的段落**（`website/blog/sc-12`、`cc-09`、`sc-10`）：博客是写作当时的快照，不是使用文档。
