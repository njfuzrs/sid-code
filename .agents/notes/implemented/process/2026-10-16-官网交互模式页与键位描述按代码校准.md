# 官网交互模式页与键位描述按代码校准

## 决定了什么

修掉 `website/use/interactive.md` 里 21 处与当前代码不符的表述，外加两处同源的代码内文案
（`defaultBindings.ts` 的 shell 模式 description、`InputArea.tsx` 的同一处注释）。按主题：

1. **键位与键位表**
   - 固定键清单更正：原写「`!`、`@`、换行、`↑/↓`、Emacs 编辑键」不走查表、改绑被拒。
     实际 fixed 项是 `!` / `@` / 换行×3 / `↑` / `Ctrl+Y` / `Ctrl+W`
     （`defaultBindings.ts:52-121`）；`Ctrl+A`、`Ctrl+K` 这类 Emacs 编辑键不在键位表里
     （`helpShortcuts.ts:37-50` 的 HELP_ONLY 集合），也无从改绑。
   - 「改绑会在启动时被拒」→「被校验拒绝」（`validate.ts:113-154`：保留键 + fixed 项两类 error）；
     FAQ 里同源的「被拒的绑定会在启动时报出来」→「静默丢弃、只在日志留痕」
     （`loadUserBindings.ts:106-112` 只 `log.warn` / `log.info`，issues 不回传 UI）。
   - `!` 进 shell 模式的前提是「输入框为空」（`InputArea.tsx:762` 的 `tb.isEmpty()`），
     原文与 `defaultBindings.ts` 原 description 都写「行首」；两处一并更正。
   - `Ctrl+G` 的编辑器解析补上 `$VISUAL`（`external-editor.ts:25-32`：优先 `$VISUAL`、其次 `$EDITOR`）。
   - `Ctrl+B` / `Ctrl+F` 括号里的「有后台任务时」不准：`Ctrl+F` 需要运行中任务
     （`App.tsx:944` 的 `hasRunningTasks`）、`Ctrl+B` 需要执行中（`App.tsx:1004` 的 busy），
     改为「有对应任务时」。
2. **多模态**
   - 「图片和 PDF 直接喂……粘贴或拖放就行」→ 图片可粘贴/拖放/@；PDF 走 Read 工具
     （`app.ts:270-273`：PDF 不在 `AT_IMAGE_EXTENSIONS`，`@x.pdf` 会被当 utf-8 文本读）。
   - Windows 剪贴板工具 `Get-Clipboard` → `[System.Windows.Forms.Clipboard]::GetImage()`
     （`clipboard-image.ts:134-137`）。
   - 「没装对应工具……静默返回 null」→ 会弹一条轻提示（`InputArea.tsx:547-551`）。
3. **Vim**
   - `r` 是 no-op（`transitions.ts:501-511`，「简化为不支持多字符，直接吞」），从「实际实现了」
     的编辑表里删掉，并到下方未实现清单与 `Ctrl+V` 并列。
   - `W` / `B` / `E` 与 `w` / `b` / `e` 走同一实现（`transitions.ts:67-75`），改
     「空白分词版本」为「当前与 w/b/e 相同（未实现 WORD 语义）」。
   - `i<` `a>` → `i<` `a<`（`text-objects.ts:28-29`）；可视模式扩展选区的键按实现列全
     （`transitions.ts:549-562` 的 `hjkl0$^wbeG` + 方向键）。
   - 导语「每条都在 `reduceNormalFirst` / `reduceVisual` 分发里」→「Vim 状态机」
     （多键组合分发在 `reduceVimEngine` 主函数，`transitions.ts:83`）。
4. **外观与语言**
   - 「四个命令都支持 `-p`」→ `/tui` 没有 `-p`（`tui.ts:31-38` 只解析 on/off，直接
     `patchSettingsFile`）；`/theme` / `/color` / `/language` 支持。
   - `/language auto` 语义：原「删除偏好字段、回退默认」（那是 `unset` 的行为）→
     「跟随用户输入语言」（`language.ts:9-17` 注释显式区分 auto 与 unset）。
   - 颜色「命名色归一化成 hex」→ `ansi:*` / hex 分形态（`color-utils.ts:120-138`：
     Ink 命名色必须转 `ansi:*` 才上色，其余 CSS 名转 hex）。
5. **FAQ**
   - Esc 连按：原「连按会触发回退选择器」→ 回退选择器只在空闲时打开
     （`App.tsx:1078-1101` 的 busy 判定），模型还在输出时连按不会触发。

## 放弃了什么（以及为什么不选）

- **不修 `website/use/sessions.md` / `start/first-task.md` 的「连按两次 Esc」表述**：
  它们只说「连按两次打开回退选择器」、未写「空闲时」前提，但不构成错误断言
  （回退是任务完成后的操作，常规即在空闲态），且不属于本次核查清单；避免扩大改动面。
- **不给 `r` 保留一行并标注「未实现」**：该节标题是「实际实现了的动作」，未实现项留在
  表里自相矛盾；改为删行 + 在下方未实现清单说明。
- **不改 `defaultBindings.ts` 其它 description**：逐条核过与实现一致
  （换行三态、filePicker、historyUpDown 等）。
- **不加机械化门禁**：这类「文档语义 ↔ 代码行为」漂移没有稳定断言可写（判断语义要靠人
  读码），沿用全站关键词扫描兜底（同「官网渲染模式与术语表归属按代码校准」的结论）。
