## 放弃了什么（以及为什么不选）

**① 放弃重跑 `w3-summary.py` 整文件再生。** 08b §4.4 写死：修完 `llm_fatal` 再跑，`collect()` 会按新 `classify()` 把 scored 改成 25/48，历史分母被覆盖。手补 caveat 是唯一不改成绩的披露。

**② 放弃用 `--ve` 注入 cc 安装镜像。** harbor `--ve` 只进 verifier；agent 安装在 agent 容器。写成 `--ve` 宿主探针全绿、每题照样打 nodejs.org。必须 `--ae`。

**③ 放弃只托主包、不托平台 optional dep。** 08a §3.7 第二条独立失败就是 `npm added 1 package` 之后 `claude native binary not installed`。optional dep 失败 npm rc=0。只托主包 = 换了一种假绿。

**④ 放弃 `python3 -m http.server`。** 与 uv 镜像同一条根因：`getfqdn("0.0.0.0")` 本机 128s，套接字卡在 CLOSED。

**⑤ 放弃只改 cc 臂的 mem.log。** sid 臂同样 `> "$MEM_LOG"`；resume 对称性要求两边一起改。

**⑥ 放弃在本 PR 对真实 `runs/` `--apply` 或重跑 A3。** 数字已收敛；D2 是下次 `SID_W3_ARM=cc` 的硬前置，不是回溯改分母。
