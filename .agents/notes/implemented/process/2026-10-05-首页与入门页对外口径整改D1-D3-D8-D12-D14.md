# 首页 / 入门页 / README 对外口径整改（D1 D3 D8 D12 D14）

## 决定了什么

- D1：TUI 重构（B9）未完成，渲染底座仍是 ink 改造而来，所以对外不再说「自研」。能力条改「行 TypeScript（含测试）」，README「Ink 自研」改「终端界面基于 ink 改造」，许可证一句改「本仓代码」。
- D3：首页企业卡「企业 SSO」改「飞书身份登录」。依据是 `packages/cli/src/command/auth.ts` 与 `packages/core/src/identity/cli-login.ts`（`sid-code auth login`，PR #161）：实现的是飞书一种身份源，不是通用 SSO 协议（SAML / OIDC 多 IdP），所以不用「SSO」这个词。
- D8：能力条与 README 中英文四个数字换成 docs-research `scripts/resume-metrics.ts --coverage` 2026-10-04 在 HEAD=f1581f76 上的同一次运行：524,786 行（测试 206,413）/ 13,398 单测 0 失败 / 引擎行覆盖 86.3%（77,768 / 90,119）/ 44 个工具（`website/ref/tools.md` 同源）。
- D12：统一成「三族（Anthropic / OpenAI / Ollama），OpenAI 族含 Chat Completions 与 Responses 两种」。依据 `packages/core/src/llm/openai.ts` 的 `shouldUseResponsesAPI`（env 强制 → 模型目录 protocolKind → 非官方端点走 Chat → gpt-5.x 兜底）。「Azure 都能接」删掉：源码里没有 Azure 专用接入（鉴权头 / deployment 路径），也没实测。`help.ts` 的 `--provider` 说明本来就是这个口径，不用改。
- D14：install 页改「保留最近 2 个版本（含当前）」。依据 `scripts/install-template.sh` 里 `KEEP_VERSIONS=2` + `tail -n +3`。
- llms.txt 顶部那句旧定位来自 `scripts/docs-gen-reference.ts` 的 `renderLlmsTxt`，现在和 `website/.vitepress/config.ts` 的 description 一致。
- 另外清了两处「对标 Claude Code」比较句、一处「一行不外流」。

- 不写「SSO（开发中）」：P2 客户端已经合入，功能是有的，只是名字要写实。
- 不改 `website/.vitepress/scaffold-pages.ts` 里的旧 description：它是一次性脚手架，不参与生成对外内容。
- 不改 `tests/website/tokenize.test.ts` 里「多 provider 可插拔」的样例句：那是分词测试用的输入，不对外。
- 能力条行数不换成「不含 fork」口径（49.6 万）：简历和 README 用的都是 resume-metrics 的合计口径，换掉反而会让三处数字对不上。把「自研」二字去掉就够了。
