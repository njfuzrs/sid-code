# CLAUDE.md 精简：发布流程与北极星指标口径外迁

## 决定了什么

根 `CLAUDE.md` 从 488 行压到 110 行，内容按「每次会话都用」与「做某件事时才用」切分：

- 发布流程（双版本并存、发版七步、beta/promote/rollback 通道、changelog、构建目标表）整段搬到 `scripts/RELEASE.md`，和 `release.sh` 放在一起。
- 四大方向的指标表（取数源、✅/⚠️/❌ 状态、TTFT/TTFB 口径铁律）搬到 `northstar/README.md`。
- CLAUDE.md 只留宗旨、四特性、四条通用铁律、会话自检、Agent Note 约定、全局约束、⛔ 不删无关文件铁律、收尾自检，每节去掉事故复盘的叙述，只留判据。
- 三个读 CLAUDE.md 的测试（`build-target-naming` / `release-channel` / `release-flow-contract`）改读 `scripts/RELEASE.md`，并新增断言「CLAUDE.md 指向 RELEASE.md」。

搬家时顺手修了五处与源码不符的内容：

- `output ÷ input 比` 标 ❌「从未做除法」→ 实际 `collector.ts` 已在算 `output_input_ratio`，改为 ✅。
- 「beta 用户不带变量 update 会静默回到稳定版」→ #204 之后 `resolveUpdateChannel` 会跟随已安装通道，改写为现行为。
- promote「纯指针实测 5s」→ 补上多版本区间的合并说明与交互确认、`--beta-fix`/`--beta-note`。
- beta 判据日期停在 2026-09-04 / v0.1.603 → 刷新到 2026-10-17 / v0.1.610，结论不变（仍未满足）。
- CONTRIBUTING 的「六道 CI 门禁」漏了 `lint:command-system`，改为七道。

另据 2026-10-09 使用报告（摩擦分析：33 次「代码有 bug」、13 次「方法不对」）补了两段，每条都回仓库核过：

- 全局约束新增：跨域源码字面量断言选测选不到（实例 `quota-effective-limit.test.ts` 读 `cli/src`，删 `maxBudgetUsd` 时 CI 首红）；新增门禁必做变异自证（3 个测试注释引用这条「CLAUDE.md 规则」，但原文并没有独立成条）；修缺陷前先核诊断；长任务增量提交（32MB 请求上限中断过两次）。
- 新增「环境与工具陷阱」：只用 oxfmt（仓内无 prettier 配置）、macOS 无 `timeout`/`gtimeout`（本机 `which` 实测均不存在）、zsh 不做 word splitting、TUI 测试吃宿主 `TERM_PROGRAM`、`UPDATE_TERM_BENCH` 会重写基线（`bench.test.ts:19`）。

## 放弃了什么（以及为什么不选）

- **报告建议的「Worktree 任务工作流」段（从 `refactor/tui-render-port` 拉 worktree）**：该分支本地与远端都已不存在（已合入 main），写进去就是新的过期内容。
- **报告建议的「推送前一律跑全量」**：与「选测 + CI 合并前全量」的既定 trade-off 冲突，真实漏网的只是跨域字面量断言这一类，用定向 grep 补，不把每次推送拖到 2 分钟。
- **报告建议「未 stash 前不要 git checkout」**：本仓禁止用 `git stash` 做基线（会卷走并行工作），保持「禁止 checkout/restore」原样，不开 stash 口子。
- **报告建议的 PostToolUse 自动跑 oxfmt hook 与 /tui-task skill**：属于 harness 配置，不是仓库约定，不进 CLAUDE.md；且 hook 里的 `npx oxfmt` 会绕开仓内锁定版本。


- **删掉 `@CONTRIBUTING.md` 注入**：能再省约 500 行上下文，但 agent 不一定会主动去读，门禁清单可能被漏跑。保留。
- **把发布流程做成 skill**：按需加载更省，但要同时被 Claude Code 和 sid-code 两个 harness 识别，未验证；纯 markdown 文件两边都能读。
- **直接删除事故叙述而不迁移**：tag 错位、promote 9 分钟窗口、ruleset bypass 否决等论证已在 `release.sh` 注释与既有 Agent Note（如 `2026-08-21-两处残留裁决-flake根因与发布流程冲突.md`）里，`scripts/RELEASE.md` 也完整保留了原文，没有信息被丢掉。
- **删除「worktree 路径含 `.claude/` 致假失败」以外的其余 worktree 教训**：只删了这一条。实测 `stripWorktreeContainerPrefix("/x/repo/.claude/worktrees/foo/src/app.ts")` 返回 `/x/repo/src/app.ts`，命中的受保护模式为空，W4 修复（673a49c1）已让它失效。
