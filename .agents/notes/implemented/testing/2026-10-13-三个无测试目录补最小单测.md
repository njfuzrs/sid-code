# 给三个无测试目录补最小单测

## 决定了什么

给 `packages/core/src/` 下三个没有同名 `tests/` 目录的 domain 补最小行为测试：
`bootstrap`（cwd-context）、`command-contract`（protected-names）、`coordinator`（mode）。
同时把 `scripts/affected-tests.ts` 里的 `CORE_SRC_WITHOUT_TESTS` 名单清空，
因为这三个目录不再需要回退整包。

## 放弃了什么（以及为什么不选）

1. **给每个目录写全覆盖的测试** —— 这三个目录合计 781 行，大部分是类型定义和纯数据
   常量，全覆盖收益低。只给最基本的行为加保护（3-6 条用例/文件），目的是让
   affected-tests 能精确命中而非回退整包。
2. **保留 `CORE_SRC_WITHOUT_TESTS` 名单并继续往里加东西** —— 保留意味着「这些目录
   永远缺测试」成了永久事实。补完测试后清空名单，将来新增的无测试目录由下方
   `existsSync` 兜底回退整包，不需要手动维护名单。
3. **改 `affected-tests.test.ts` 的断言** —— 那条「src 独有目录回退整包」的断言
   仍然需要保留（覆盖将来新增的无测试目录），只改注释说明，不改断言逻辑。

## 拿什么证明它生效了

```
bun test ./packages/core/tests/coordinator/ ./packages/core/tests/command-contract/ ./packages/core/tests/bootstrap/
→ 17 pass / 0 fail

bun test ./tests/scripts/affected-tests.test.ts
→ 42 pass / 0 fail

bun run scripts/affected-tests.ts
→ 判定：selective，命中 ./packages/core/tests/coordinator/ 等三个目录（不再回退整包）

make build → rc=0，无 "will always be undefined"
bun run lint → 0 warnings, 0 errors
bun run format:check → All matched files use the correct format
bun run lint:boundary → 0 越界
```
