# 设备凭据是否失效只认服务端 401，本地 expires_at 降为展示用快照

## 决定了什么

服务端设备凭据是滑动续期（每次鉴权通过把 `expires_at` 往后推一个 TTL），客户端本地文件里的
`expires_at` 是登录那一刻的快照、从不更新。以前本地一过期就扣下凭据，于是登录满一个 TTL 的
活跃用户会静默失去全部企业通道（策略 / 预算 / 账本 / 事件 / 插件市场 / `sid-backend` MCP），
而服务端那边凭据其实还有效（B1）。连带两处：本地过期后 `logout` 跳过服务端解绑，换人登录撞 409（B2）；
`auth status --verify` 跳过服务端核验，用户无法自查（B3）。

- `packages/core/src/identity/credential.ts`：`getUsableCredentialToken()` 本地过期仍返回凭据，
  只打一次 debug（原来是 warn + 返回 undefined）。
- `packages/core/src/identity/cli-login.ts`：`performCliLogout` 直接取 `getDeviceCredential()?.credential`，
  不依赖 `getUsableCredentialToken` 的语义。
- `packages/cli/src/command/auth.ts`：`--verify` 本地过期也调 `/ctl/whoami`；本地过期不再算未登录；
  新增「登录时间」（`enrolled_at`）；过期行注明「本地记录，服务端每次使用自动顺延」（不写死天数）；
  logout 在没配 backend.url 时提示未通知服务端解绑。
- 事件 / 账本 401 告警里「本会话不再重试」与实际行为不符（实际是这一批丢弃、下一批照发），改成如实描述。

契约变更：`identity.test.ts`「过期凭据不带 Authorization」与 `http-exporter.test.ts`「过期凭据不发远程」
两条前提随之改为「本地过期仍发送」，并新增「本地过期 + 服务端 401 → 丢批、不写盘」守住 fail-closed 那一半。

## 放弃了什么（以及为什么不选）

- **客户端模仿服务端滑动续期（每次请求成功就把本地 expiresAt 推后 90 天）**：否决。客户端要硬编码
  服务端 TTL（`CTL_CREDENTIAL_TTL_DAYS`），服务端改配置就再次漂移，是把同一个 bug 换个位置。
- **只靠服务端在 whoami 回传续期后的 expires_at、客户端启动时同步（方案 A）**：不单独采用。
  第 TTL 天之后才启动的那一次，同步请求本身会被本地过期拦住，除非同步时无视本地过期——那就回到了本方案。
  它负责「显示正确」，作为后续 PR（agent-backend 加字段 + 客户端同步）独立上线，不阻塞本修复。
- 代价：凭据真过期时，每条通道会多发一次注定 401 的请求（之后各自只告警一次）。凭据只发往
  backend.url 同源地址，本地过期不扩大泄露面，可接受。

## 拿什么证明它生效了

- `bun run affected-tests:run`（本次判定为全量）：16375 pass / 1 fail，唯一失败是新用例把 whoami 次数断言成
  恰好 1 次，而 `--verify` 的企业通道探测会再调一次 whoami；已改为「至少一次」，单跑 4 pass / 0 fail。
- 新增用例覆盖：本地过期仍带 Bearer 且只 debug 一次；本地过期仍发事件；本地过期 + 401 丢批不写盘；
  本地过期 logout 仍调 `/cli/logout`；`--verify` 本地过期仍调 whoami（200 → ok 且已登录，401 → 未登录）。
- 变异自证：把 `auth.ts` 的核验条件改回 `!backend || !cred || expired`，`auth-status.test.ts` 2 fail；恢复后 4 pass。
- `make build` 通过，无 `will always be undefined`；lint / format:check / lint:boundary / docs:gen-reference 全绿。
  `typecheck:gate` 报 1 条 `packages/tui/src/ink.tsx` TS1192，父仓 main@28d5d204 同样复现（本机残留
  signal-exit 4.1.0），与本次无关。
- 尚未做的端到端验证：真实后端上把本地 `expires_at` 改成过去时间，确认七条通道仍正常
  （需飞书账号与线上后端，单测覆盖不到）。
