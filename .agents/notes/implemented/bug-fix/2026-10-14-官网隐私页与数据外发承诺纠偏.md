# 官网隐私页与数据外发承诺纠偏（数据主权整改 PR-C）

## 决定了什么

数据主权整改的最后一步：官网文档按 v0.1.609（PR-A1 #260、PR-A2 #264、PR-B #272 均已发布并 promote）的实际行为重写。

- 新增 `website/use/privacy.md`「隐私与数据流向」，作为隐私问题的**唯一事实源**：本机存储、出网总表（默认出网 / 需配置才出网两张表）、模型侧留存、三个隐私级别对照与刻意保留项、脱敏范围、上传形态与补传语义、安装链路、陌生仓库边界、企业锁定方式、FAQ。其余页面只写一句结论并链过去。
- 纠正过满承诺：README「不进任何人的训练集」、`start/index`「数据留在本地」改为可核验表述（sid-code 不回传会话内容；模型侧留存取决于 provider）。
- `team/observability.md`：首段写明只写本机、只上传配置之后的会话；保留策略统一为 365 天 / 10GB（删掉两处「100 个」旧口径）；补脱敏说明、`SID_CODE_TRACE_NO_RAW`、上传文件与标识字段表、三个上传时机、`--include-history`、env 与 CLI 两层整块替换 `trace` 的完整影响面、四道闸门展开、essential-traffic 覆盖面。
- 源码描述（生成参考页的源头）：`trace.enabled` JSDoc 默认值 false→true、`privacyLevel` JSDoc、`help.ts` 两个隐私环境变量、`/debug` 命令 description 写明上传前提、`uploader.ts` 注释的旧保留口径；随后 `docs:gen-reference` 重新生成。
- 其它页面：defaults / install / auto-update（更新检查发了什么）/ memory / troubleshooting / permissions（搜索词与抓取 URL 去向）/ policy（用托管配置 `env` 锁定隐私级别）/ SECURITY（新增两类「算漏洞」、两条已知现状）；侧栏「权限与安全」组加入口。

写之前按最终代码复核了出网与脱敏，与方案的三处差异以代码为准：

1. **插件市场（v0.1.609 新增）是方案盘点里没有的出网**：`cli/src/plugin/market.ts:111` 官方 index，交互启动时对已装市场插件拉目录（`ui/App.tsx:664-666`、`plugin/auto-update.ts:76-98`），`plugin/` 下隐私级别判断 0 命中，即**不受 essential-traffic 控制**。文档如实写为刻意保留项之外的「目前不随隐私级别关闭」，并给出 `officialMarketplace: false` 的关法。
2. **记忆写入的 secret 检测不与轨迹脱敏共用规则表**（`memory/write-guard.ts:43` 用 `llm/hooks/secret-redact.ts` 的 7 类规则），方案 D25「同一套规则」的改法不成立，改为「独立的常见凭证规则，覆盖面比轨迹脱敏窄」。
3. **`trace.recordRawPayloads` 写在 settings.json 里不生效**：`config.ts` 的 trace 段转换只保留 enabled / outputDir / maxSessionsRetained / upload，该字段被丢弃，只有 `SID_CODE_TRACE_NO_RAW=1` 有效。文档只写环境变量。

D28（企业能否锁定）结论：没有专门字段，但托管配置 `env` 设 `SID_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` 可强制 essential-traffic（`settings/managed-env.ts:24,111-116` + `analytics/privacy-level.ts:28`），只有系统级路径才算锁定。

## 放弃了什么（以及为什么不选）

- **不在本 PR 修上面差异 1 和 3 的代码**：本 PR 是文档 PR，混入行为改动会让 review 分不清「文档跟代码」还是「代码跟文档」。两条作为后续代码任务提出；文档先如实写现状，修了再改那一行。
- **不改 `redact_home_dir` 默认值**：仍待与平台侧对齐，文档按「默认关」写。
- **不做 `/doctor` 提示已关闭项**（方案 §7 A2 应对项）：用隐私页「三个隐私级别」一节的对照表覆盖，不改代码。
- **SECURITY 不写漏洞利用方式与已修复的漏网形态**：按方案 §4.2，只写最终边界与「算漏洞」的类别。
- **首页 hero 不动**：现有 tagline 不含数据承诺，定位块措辞只在注释里，改它超出本任务。
