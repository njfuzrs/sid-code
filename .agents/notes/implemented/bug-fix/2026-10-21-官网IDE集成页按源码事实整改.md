# 官网 IDE 集成页按源码事实整改，并补齐扩展侧 wire 契约

## 决定了什么

`website/extend/ide.md` 全文按 `packages/{core,cli}/src/ide/*` 的当前实现重写，`website/extend/index.md` 两处「VS Code / JetBrains」改为「VS Code / Cursor / Windsurf」。具体纠正了：

- **lockfile 字段**：端口**只从文件名** `<port>.lock` 解析，JSON 内容里没有 `port`（`lockfile.ts:36-37`）；补全实际支持的 `workspaceFolders` / `pid` / `ideName` / `transport` / `authToken` / `runningInWindows` 六个字段与过期清理判据。
- **删除「没有扩展时日志不会出现」**：`integration.ts:81-87` 在 `shouldAutoConnect()` 为 true 时就打印「开始搜索可用 IDE...」，与 lockfile 是否存在无关。
- **日志可见性**：快速上手的验证手段从「看日志」改为 `/ide status`，并说明 INFO 级日志在默认审计模式（`level: WARN`）下既不落盘也不上屏、TUI 下 `--debug` 也只写文件（`cli.ts:1554-1585`、`logger.ts:362`）。
- **能力数量**：从「四个能力」改为「三个」（选区 / @提及 / diff），与 `integration.ts` 的三条实现一致。
- **自动连接条件补 `--ide`**（`help.ts:89`、`cli.ts:812-813`），并补 `SID_CODE_SSE_PORT` 的「命中即采纳、不做工作区/祖先消歧」语义（`detect.ts:74-78`）。
- **状态四态**（`… 连接中` / `✗ 已断开` 之前漏了）、`/ide status` 未连接时两种提示分支、30 秒发现窗口、多实例自动连接静默放弃。
- **选区 / @提及注入形态**补上 `<ide-selection>` / `<ide-mentions>` 包裹与选区去重语义（`integration.ts:307-343`）；修正原 64-72 行嵌套代码块写法（内层 ``` 会提前闭合外层，渲染成空代码块），改用四个反引号。
- **新增「扩展侧需要实现什么」一节**：lockfile、`selection_changed` / `at_mentioned`（不带 `notifications/` 前缀）、`ide_connected`、`openDiff` / `close_tab` / `closeAllDiffTabs` 的 snake_case 参数与 `FILE_SAVED` / `DIFF_REJECTED` / `TAB_CLOSED` 响应字面量（`protocol.ts` 全量、`diff.ts:127-132`）。
- FAQ 里 lockfile 缺失文案改为代码实际输出的小写 `vscode`，并注明这是内部枚举值（代码侧的显示名缺陷另立文档，见 `docs-research/sid-code/bugfixes/todo/20261021-IDE集成-核查官网发现的代码缺陷.md` 的 D1）。

## 放弃了什么（以及为什么不选）

- **不改 frontmatter 的 `description`**：它本身没有事实错误，改它要连带重跑 `docs:gen-reference` 并动 `website/public/llms.txt`，收益不足以承担额外漂移面。
- **不把 wire 契约塞进「连接机制」一节**：那会让「怎么连上」的叙述被协议细节打断。新增独立一节，`::: warning` 里同时链接两节，读者可按身份（用户 / 扩展作者）各取所需。
- **不在本 PR 改代码**：D1-D6 六条代码缺陷（显示名、死代码、状态残留等）需要产品决策（如 `closeAllDiffTabs` 是删是接线），按「代码缺陷只出文档、文档错误立即修」的分工拆开，避免文档 PR 混入行为改动后无法独立回滚。
- **不扩写 `/ide install` 的历史**：保留一句「已移除」即可；展开会变成变更日志，不是使用文档。
