# 后台任务等待期的轮询：三处回执改禁令，主循环拦截运行中任务的看进度调用

## 决定了什么

opus 批次 5 个样本里，后台任务运行期间主代理发了 28 次「看进度」调用，7 次撞空报错（`events.jsonl` 口径）。根因是能拿到 `.output` 路径的三个入口都在给许可或给错误出路，harness 侧没有兜底。

- **三处回执共用一个禁令常量** `BACKGROUND_RECEIPT_NOTICE`（`task/background-receipt.ts`，零依赖叶子模块，因为 `tool/bash.ts` 对 task 模块一直是惰性 require）：子代理后台回执（`agent/tool.ts`）、bash 后台回执、Ctrl+B 转后台回执（`tool/bash.ts`，原先没有任何不要轮询的说明）。去掉了「用户要求时可 read output_file」「需要看进度时 read output_file」两句许可。
- **主循环拦截**：`query/tool-executor.ts` 的 `executeSingleTool` 在权限与 PreToolUse 之后、`tool.execute` 之前调用 `checkBackgroundPoll`（`task/background-poll-guard.ts`）。命中以下三类时不执行，返回非错误的「仍在运行，完成后自动通知」：read 运行中任务的 `.output`；bash 引用 tasks 根目录（绝对 / realpath / `~` / `$HOME` / `${HOME}`）或运行中任务的 `<id>.output`；对运行中任务的 `task_output` / `bg_task_get`（`block !== false`）。终态任务、`block=false` 快照、`tasks/sessions/`、`tasks/<team>/`、自身 `run_in_background` 的命令都放行。命中时发一条 `BackgroundPollIntercepted{tool_name, tool_use_id, kind, task_ids}` 进轨迹（`cli/src/app.ts` 接 sink），Pre/Post 照常配对。
- **墓碑区分运行中**：`formatTaskOutputTombstone` 新增 `liveStatus` 参数（由 `read.ts` 从 registry 查到后传入；lifecycle 不能 import registry，否则成环）。运行中改为「仍在运行，尚未产出输出」；无墓碑的已清理分支改为推荐 `task_output(block=false)`，不再推荐默认阻塞的调用（S3v 里模型照旧文案连发 3 次阻塞 `task_output`）。
- **循环检测轮询恢复提示**（`agent/loop-detection.ts`）第 1 条从「阻塞等待 bg_task_get({block:true})」改为「结束本轮，完成后自动通知」，不再把模型指向一条会被拦截的路。
- **删 system「后台任务不要轮询」整段，中英两份同删**（`config/system-prompt.ts`、`config/prompt-sections-en.ts`）。「按需拉取完整结论」保留：已完成任务读 `<output-file>` 是合法入口。

等待由 `-p` / stream-json 的后台续跑（`app.ts` `waitForBackgroundNotification`）保证，不靠模型；本改动不碰这条路径。拦截只接主循环：子代理不能派后台子代理，后台 bash 回执也只回到派发者。

牺牲：更准一侧的一个入口。用户要看运行中进度时，模型不能再 read `.output`，只能 `block=false` 快照或指向 TUI 面板。换来的是更快、更省（等待期工具调用与撞空失败归零）。

## 放弃了什么（以及为什么不选）

- **只改文案**：cc 靠文案在 5 个样本上做到 0 次，但 F3 要用 deepseek flash 跑，P2 已测到 opus 都会被一句 20 字的许可带偏，弱模型没把握；而且 S3v 那 3 次 `task_output` 来自 deferred 工具的默认 `block=true`，文案管不到工具默认值。
- **回执去掉 `output_file`、`block` 默认改 false**：完成通知里的 `<output-file>` 是「按需拉取完整结论」的入口，不能去，回执去了模型照样从通知拿到路径；`block` 默认 true 是对齐 cc 的对外契约（`task-get.ts` 注释），影响面大于本项。
- **只拦截不改文案**：拦截文本会成为新的「离行动最近」的文字，但模型每次得先撞一次才看得到，尝试次数降不下来，等于把撞空换个名字。
- **加 settings 开关**：没有需求，不先加配置。
