# diff 增删行底色铺满到 terminalWidth

## 决定了什么

`packages/cli/src/ui/components/DiffRenderer.tsx` 的 React 路径（≤80 行的小 diff）里，add/del 行的内容区外面套一层 `<Box flexGrow={1} backgroundColor={...}>`。整行底色由这个 Box 提供，不再只靠内容 `<Text>`。

根因：`<Text backgroundColor>` 的底色只包住文字本身，最后一个字符后面就输出 `\x1b[49m`，行尾空白没有底色，所以红绿块看起来长短不齐。Box 的底色由 tui 的 `renderBackground` 按 Yoga 算出的宽度整块铺空格，`flexGrow` 把内容区撑满到 `terminalWidth`。行号槽本来就是带底色的 Box，所以现在整行连成一片。

RawAnsi 路径（>80 行，`diffAnsiLines.ts`）原本就用补空格铺满，这次没动。改完后两条路径的表现一致。

## 放弃了什么（以及为什么不选）

- **在 Text 末尾手动补空格**：需要自己算 CJK 宽度和折行后每一行的剩余列数。`wrap="wrap"` 折行后只有最后一行会被补到，前面的折行仍然不齐。Box 底色按计算出的高×宽整块铺，折行也能覆盖。
- **把小 diff 也统一走 RawAnsi**：会丢掉 React 路径保留的可选中文本和无障碍语义（DF3 当初特意留下的），改动面也超出这个 bug。

## 拿什么证明它生效了

- 新增 `packages/cli/tests/ui/components/diff-row-background-full-width.test.tsx`：在 terminalWidth=40 下断言 3 条增删行的可见宽度都是 40，行尾是空格加唯一一次 `\x1b[49m`。
- 变异自证：把 DiffRenderer 回退到修复前，该测试变红（`Expected: 40 / Received: 12`）；恢复后变绿。
- 修复前后探针帧对比：修复前 `…new\x1b[22m\x1b[39m\x1b[49m`（底色在词尾结束）；修复后 `…new…\x1b[48;2;33;92;51m` 再接 23 个空格，最后才是 `\x1b[49m`。
