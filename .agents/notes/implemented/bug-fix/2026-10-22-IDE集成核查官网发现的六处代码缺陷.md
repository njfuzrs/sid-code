# IDE 集成：修掉核查官网时发现的六处代码缺陷（D1-D6）

## 决定了什么

- **D1**：`packages/core/src/ide/process-tree.ts` 新增 `DETECTABLE_IDE_DISPLAY_NAME`（`Record<DetectableIDE, string>`），
  `/ide` 的「没有 lockfile」提示经它映射后拼接，用户看到 `VS Code` 而不是内部枚举 `vscode`。
  `noLockfileMessage` 的参数从 `readonly string[]` 收窄为 `readonly DetectableIDE[]`，以后加 IDE 漏写显示名是编译错误。
- **D5**：`IDEIntegration.connectToIDE` 在「未连上」和 catch 两条失败分支里调 `removeServer("ide")`。
  原因：`MCPManager.addServer` 失败只断 client、不删 `serverConfigs`，而 `disconnect()` 以 `currentIDE` 为清理条件，
  失败路径不设置它，于是 `/mcp` 面板会留一个连不上的 `ide` 条目。
- **D6**：`detect.ts` 新增 `parseSsePortEnv`，`shouldAutoConnect` 与 `detectIDEs` 共用。
  非 1-65535 整数（`abc` / `0` / `123abc` / `70000`）不再触发自动连接，并打一条 WARN。
- **D2**：删除零调用的 `showEditDiffInIDE`（`tool-hooks.ts`）。
- **D3**：删除零调用的 `closeAllDiffTabs()` 函数（`diff.ts`）。`IDE_RPC.closeAllDiffTabs` 常量保留，它是扩展侧的 wire 工具名。
- **D4**：`collectIDEContext` 的注释从「供 /ide 状态展示」改成「无生产调用方，仅测试使用」，`system-prompt.ts` 的引用注释同步。
- 官网 `website/extend/ide.md`：示例文案改成 `VS Code` 并删掉「小写枚举」说明；补非法 `SID_CODE_SSE_PORT` 的行为；
  `closeAllDiffTabs` 一行注明 sid-code 当前不调用。

## 放弃了什么（以及为什么不选）

- **D3 选项 B（会话结束时调 `closeAllDiffTabs` 兜底）**：缺陷文档倾向 B，理由是 `negotiateContentViaIDE` 的 catch 分支不关 tab。
  回源码核实后发现这条分支走不到：`callIDERpc`（`rpc.ts`）吞掉全部异常并返回 null，`showDiffInIDE` 又把 RPC 和路径换算整个包在 try 里，
  异常都会变成 `{action:"error"}`，而 error 分支本来就 `closeDiffTab`。为一条走不到的路径接一个「关全部」，
  还会顺带关掉用户正在看的其他 diff（正是当初补 `close_tab` 要解决的问题），所以选 A。
- **D4 直接删 `collectIDEContext`**：`context-delta.test.ts` 用它锁「未连接时恒为空」这条历史结论，删了要连带改测试。收益小，只收窄注释。
- **D5 改 `disconnect()` 的清理条件**：`MCPManager` 没有 `hasServer`，为此新增公开方法会扩大改动面。在失败分支里就地 remove 改动更小、语义更直接。
- **拆成两个 PR（文档建议 PR-A 行为 / PR-B 清理）**：六条都在 `packages/core/src/ide/` 一个模块里，都是低严重度，没有「上线时机」上的差别。
  按 CONTRIBUTING「三条全过时按关注点合到最大」合成一个 PR，用分开的 commit 保留可读性。

- `bun test ./packages/core/tests/ide/ ./packages/cli/tests/command/ide-no-lockfile-message.test.ts`：全绿（新增 D1 显示名、D5 失败移除、D6 解析与自动连接共 5 条用例）。
- 变异自证：
  - 把 `connectToIDE` 失败分支的 `removeServer` 注释掉 → D5 用例红（`removed` 为 `[]`）。
  - 把 `shouldAutoConnect` 改回 `process.env.SID_CODE_SSE_PORT ||` → D6 自动连接用例红。
  - 把 `noLockfileMessage` 改回 `running.join("、")` → 源码断言用例红。
- `grep -rn "showEditDiffInIDE\|closeAllDiffTabs(" packages`：删除后无残留调用。
