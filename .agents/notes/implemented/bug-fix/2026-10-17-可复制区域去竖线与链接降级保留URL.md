# 可复制区域去竖线 / 前导缩进，链接降级保留 URL

## 决定了什么

承接 #321（markdown 代码块去行号），按「复制下来能不能直接用」排查同类问题，一次修齐：

1. **链接降级丢 URL**（`markdown.ts` `renderLink`）：不支持 OSC 8 时此前只输出带下划线的 label，
   URL 完全不可见。现改为 label ≠ URL 时输出 `label (url)`，label 即 URL（autolink）时只输出 URL。
   对齐 CC `utils/hyperlink.ts` `createHyperlink`（不支持时返回 url）。支持 OSC 8 的路径不变。
2. **计划评审 round 全框**（`PlanReviewMessage.tsx`）：改为 `single` + 去左右竖线，内容宽度 `-4` → `-2`。
3. **错误面板左竖线**（`ErrorPanel.tsx`）：去掉 `borderLeft`；错误语义由标题行 `✘` + 红色承担（字形 + 颜色双通道，L2.1）。
4. **初始化错误 round 框**（`Notifications.tsx`）：改为与启动警告同构的「3 列标记列 + 正文」，标记用 `ERROR_MARK`。
5. **更新提示死接线**：`setUpdateInfo` 全仓零调用方，`UpdateNotification` 永不渲染。
   删除组件与 `UIStateContext` 的 `updateInfo / setUpdateInfo / UpdateInfo`。真实的更新提示路径是
   `App.tsx` 消费 `pendingNotice` → `showTransientMessage`，不受影响。
6. **`renderMarkdown` 代码块 2 空格缩进**（`markdown.ts` `case "code"`）：去掉，与 `MarkdownAnsi` 同口径。
   列表项内代码块的悬挂缩进由 `renderList` 负责，属 markdown 结构语义，保留。

判据统一用 `src/ui/CLAUDE.md` L2.2：**这块内容用户会复制吗？** 会 → 不画与内容同行的字符。

## 放弃了什么（以及为什么不选）

- **ErrorPanel 保留竖线当语义标记**：竖线和 detail / suggestion 同行，而这两行恰恰是最常被复制的
  （报错原文去搜、建议命令去跑）。语义已有 `✘` + 红色双通道兜住，竖线是第三通道，代价是污染复制。
- **链接降级时只显示 URL、丢掉 label**（CC 的做法）：中文回复里 label 常承载「这是什么链接」，
  丢掉后一串 URL 不知所指。`label (url)` 多占几列，但 URL 本身不加样式、拖选复制干净。
- **把更新提示接通而不是删掉**：真实链路已经走 transient message 并且有测试，再接一条持久横幅是重复通道；
  死字段留着只会让下一个人以为「更新提示走 updateInfo」。
- **引用块 `│ ` 前缀、各设置对话框的 round 框**：前者 CC 同样画，属语义标记；后者是纯展示面板，L2.2 明确保留。
- **超长命令软折行导致复制断行**：CC 同样交给 Text 折行，对齐 CC 不算缺陷，独立议题。
