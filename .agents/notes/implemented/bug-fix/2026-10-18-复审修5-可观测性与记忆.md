# 复审修-5：digest 收尾判据、记忆 key 回退、快照标记与失败归类

## 决定了什么

对应 `20261018-任务静默停住修复落地复审-遗留问题清单.md` §6 修-5（B4 + M2 + M4 + L8–L11 + T8）：

- **B4**：`digest.ts` 新增 `resolveDigestDuration`，「进行中」只认 traj metadata 的 `session_ended`。`session_ended=false` 时时长优先取增量账本的 elapsed，并标注进行中。旧 traj 没有这个字段时沿用旧口径。原判据「有账本 = 已收尾」不成立：`flushSessionLedgerIncremental` 每轮 done 都会 upsert。
- **M2**（§8 决策 1）：`resolveMemoryKey(key, entries, files)` 改为「精确 → 去 `.md` → 按 `files` 反查真实文件名」，删掉剥类型前缀的回退。5 个调用点都传了对应 scope 的 `files`。
- **M4**：`markUploadedKeepLocal` 在写 `final:false` 前先查 `hasFinalUploadMarker`。已经是终态时整步跳过，连 metadata 快照也不重写。终态只许前进不许后退。
- **L8**：`classifyToolFailure` 改用 `TIMEOUT_EVENT_RE`，只认超时事件的措辞（timed out / ETIMEDOUT / XxxTimeoutError / timeout after|exceeded / 「超时」后面不跟 时间|参数|设置|值）。裸词 `timeout` 不再算。
- **L9**：digest 读侧新增 `resolveLiveExitStatus`：traj 是 `exit_status:"live"` 且 PID 核验不在（无条目或 kill(0) 失败）时报 `dead`，`dead` 进入异常名单。详情页和会话列表同源。PID 目录由 `dirname(ref.dir)/../.pids` 派生，与 `findSessionProcess` 同口径。
- **L11**：load 时归一化 name，收集「已占用 name」和取 rawName 都改用 `readMemoryFrontmatter`，改写也限定在 frontmatter 块内。
- **T8**：B4、M2、M4 的反例都已补成用例，见第三段。

**L9 的跨域口径变化（点破）**：`evals/bench-runner/outcome-grader.ts:115` 只把 `end_turn` / `tool_use` 算作 `normal_exit`。S12 之后被强杀的评测会话不再被推断成 `end_turn`，分数口径因此会变，方向是对的。本次只改 digest 读侧，不改 builder 写入的 `live`，所以 grader 收到的值没有变化。

**L10 的状态：未确认**。中途快照省略 `end_time`（`uploader.ts` 的 metadata 快照、`builder.ts` 的 metaOutput），本次**没有**向服务端确认云端是否接受缺 `end_time` 的 metadata：本地没有可用的服务端源码或接口文档。当前处理方式是维持省略，不用「现在」去补，因为补了就会把进行中会话报成已结束（S12 要修的正是这个）。云端如果要求必填，表现会是快照上传 4xx，`allConfirmed=false` 进重试队列，SessionEnd 时带 `end_time` 的终态上传不受影响。需要维护者向服务端核实后再关掉这一项。

## 放弃了什么（以及为什么不选）

- **M2 只认 `_` 分隔的剥前缀**：否决。`user_auth` 这类合法 key 仍会撞上已有的 `auth`。分隔符规则判断的是「像不像文件名」，换哪种分隔符都有误伤面（§8 决策 1）。
- **M2 `set` 不回退、只有 `get/delete` 回退**：否决。`set("project_x")` 会新建第二条，S9 路径 A 原样复发。
- **M2 剩余盲区**（接受）：合法 key 恰好等于另一条记忆的文件名去掉 `.md`，且它自己还不存在时，会被当成那条。概率极低。
- **M4 在 SessionEnd 时取消或等待在途快照**：否决。要在 collector 和 uploader 之间引入跨对象的取消协议，而守卫只需一个已有的读函数，覆盖的也是同一个时序。
- **L9 在 builder 写入侧改 `live`**：做不到。写快照时进程还活着，无法预知自己之后会被强杀，只能在读侧核验。
- **L8 收窄成白名单式的完整句**：否决。各工具的超时文案分散在多处，逐句白名单会随新文案漂移。改成按「事件动词 / 错误类名」匹配。
