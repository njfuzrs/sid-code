# LLM 错误「一次判死」改为观测证据制：两条到达路径归一、有时效嫌疑态、放弃后就地重试

## 决定了什么

- **错误归一**（`llm/error-normalize.ts`）：throw 与流内 `error` 事件先变成同一个 `NormalizedLLMError`，再交给唯一分类器 `classifyFamily`。`arrival` 只进遥测、不参与决策。会话 20261008-173228-baeb949d 的 `Token已失效，请重试` 走事件路径，5ms 内判死、零重试，根因就是两条路径各有一个分类器。
- **分类只调预算，不判生死**（`llm/recovery-policy.ts`，纯函数 `decideRecovery`）：auth_suspect 同指纹 3 次（首次立即重试并刷新凭据）、request_suspect 2 次、local_fault 2 次（不退避）、transient 按调用方预算，认不出的子集同指纹 3 次封顶；所有族下限 2 次。只有闭集 `I1_EXCEPTIONS`（用户中断 / 上下文溢出转交 / `x-should-retry:false` / 后台 529 / 时间预算）能在首次观测后结束调用。
- **上下文溢出零重试转交**：判定先于族查表，只认 `isPromptTooLong`（补了 413 / `request too large`，排除附件过大），原文透传给 loop 的 reactive compact，不拉黑、不进 fallback。
- **availability**：terminal 永久态 + retry_once 合并为有时效的 suspect（默认 60s，成功产出即清）。主线程 / headless 不读嫌疑（engine 显式传 `querySource:"main_thread"`）；其余来源嫌疑期内只放一路半开探针，探针失败续标不发还。`resetTurn` 删除。
- **放弃后可就地重试**：`FallbackDecision` 增加 `retry_same`，弹窗置顶「重试当前模型」，每次调用最多 2 次，继承已用重试次数与 deadline。放弃文案带证据（次数、族/原因、状态码序列、跨度）和「直接重发会重新请求该模型」。
- **可观测**：新增 `recovery_give_up` / `unrecognized_error` 遥测，digest 新增 `recovery` 节（`oneShotKillCount` 北极星恒为 0、`deadlineGiveUpCount`、各族救回率）。`recordTurnError` 清配对看门狗，消除 5 分钟后的假 `ModelCallUnpaired`。

## 放弃了什么（以及为什么不选）

- **往词表 / 占位句白名单补「Token已失效」「upstream_error」「Connection error.」**：只修已知三例，下一个网关换措辞就复发。结构问题是「分类器结论决定生死」，词表准确度现在只影响退避节奏。
- **所有错误无限重试**：违反 I2，真 key 作废时用户卡在退避里看不到结论。persistent 仍是唯一的显式无界开关，且只解除 transient。
- **未识别措辞自动学习进规则表**：会把一次网关事故学成永久规则，等于重建「认出文案就判死」。`unrecognized_error` 只做台账。
- **在共享 availability 上打「本轮首发豁免」标记**：先跑的 side-call（memory recall 等）会把豁免消费掉，主线程仍被拦。改为按 `querySource` 判定，C 组顺序变体钉住。
- **用 LLM 判断可否重试 / 按网关写错误映射配置作主修法**：前者不确定且本身会失败；后者是词表方案换了个地方放。
- **设计稿里的 `applyRecoveryAction` 独立函数**：落地时动作分派留在流式 catch 的四个分支里（拆出去要传十几个局部变量），状态写入收敛到放弃出口 `recordGiveUp`，静态门禁钉的是后者。

## 拿什么证明它生效了

- `tests/llm/recovery-invariants.test.ts`（A 组）：21 状态码 × 11 措辞 × 7 上游 type × 3 到达形态全量断言 I1；I2 有界；I3 归一化层逐字段相等 + 执行层命运相同。变异自证：401 映射回立即放弃 / 溢出判定挪到族查表之后 / 事件路径丢状态码，A1/A3 均变红。
- `tests/llm/incident-20261008-token-expired.test.ts`（B 组）：事故原始事件首次 401 → 主模型自愈不降级；持续 401 → 3 次后放弃且证据完整；溢出转交原文透传；附件过大 413、本地 TypeError、`fetch failed`、持续 429 各一条反例；`retry_same` 有界。
- `tests/llm/recovery-cross-turn.test.ts`（C 组）、`tests/llm/recovery-single-exit.test.ts`（D 组，剥注释后匹配）、`tests/trace/recovery-digest.test.ts`。
- 线上口径：发版一周后 `northstar-snapshot --weekly` 的 `oneShotKillCount` 为 0；非零时回到 `recovery_give_up` 的证据定位，不去补词表。
