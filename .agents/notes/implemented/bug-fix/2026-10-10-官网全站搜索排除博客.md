# 官网全站搜索只收录用户说明文档，整个 /blog/ 目录不进索引

## 决定了什么

全站本地搜索（vitepress local + minisearch）不再收录 `/blog/` 下任何页面，`/changelog` 维持原有的 `search: false` 排除。
判据抽到 `website/.vitepress/search-scope.ts` 的 `isExcludedFromSearch(relativePath, frontmatter)`，
`config.ts` 的 `search.options._render` 改为调用它。按目录前缀 `blog/` 判定，依据是 vitepress 1.6.4 在调用 `_render` 前就把 `relativePath` 放进了 env（`node_modules/vitepress/dist/node/chunk-*.js`：`const env = { path: file, relativePath, cleanUrls }`）。

## 放弃了什么（以及为什么不选）

- 给 68 篇文章逐篇加 `search: false`：新文章漏加时博客会悄悄重新出现在搜索结果里，没有任何东西报错。按前缀判定的话，新文章默认就被排除。
- 用 `srcExclude` 排除 blog：那会让博客页面整个不参与构建，不可接受。
- 在搜索结果 UI 里加分组或过滤：用户要的是「搜不出来」，不是「换个位置显示」，而且要改主题组件。

## 拿什么证明它生效了

- `bun run build`（website）前后对比索引 chunk `@localSearchIndexroot.*.js`：前 68 篇 `/blog/` 路径，后 `/blog/`=0、`/changelog`=0、`/use/` 页面 10 个仍在。
- `bun test ./tests/website/search-scope.test.ts`：6 pass / 0 fail。其中构建产物断言在改动前的旧产物上是红的（1 fail），说明它能拦住回归。
