# 可观测性 P0×5 + span 树三条：外发隐私门控、计价口径、preview 脱敏、并发父子关系

来源：`docs-research/sid-code/bugfixes/todo/20260927-可观测性-顺着sc-x1-observability核出的缺陷.md`
的缺陷 1 / 2 / 3 / 12 / 21 / 28 / 32 / 35。

## 决定了什么

- **缺陷 21 / 35（外发隐私）**：门控挂在**出网动作**上，而不只挂在「通道注册处」。
  - OTLP：`telemetry/index.ts` 的 `createExporter` 在 `isTelemetryDisabled()` 时不注册 otlp（console / jsonl 是本地落盘不受影响）；
    `OtlpTelemetryExporter.exportSpans/exportMetrics` 出网前再判一次（纵深）。`initTelemetrySystem` 先注入配置文件的 `privacy_level`，保证注册时判据已就位。
  - analytics 远程后端：注册判据从 `shouldLoadRemoteConfig()`（「能否**拉**」）改为 `!isTelemetryDisabled()`（「能否**推**」）；
    `EventDiskCache.retryPreviousBatches` 在禁用时直接返回、**文件原样留盘**（不发、不删）。
- **缺陷 12 / 32（计价）**：`TokenMeter` 的全价假设改用 `normalizeCacheUsage(...).promptTotal`，与 `SessionState.calculateSavings` 同口径；
  `costUSD` 变为可选，缺省时按 model 定价回算；子代理不再传 `costUSD: 0`。`CostCalculator` 透传 provider。
- **缺陷 28（脱敏）**：两个 `_preview` 属性先 `maskSensitiveData` 再截断；`system_prompt_bytes` 改按脱敏后字节，与 event 的 `content_bytes` 同口径。
  原测试 `preview === 原文` 的断言保留成立（该用例无敏感内容），新增带密钥的反向用例。
- **缺陷 2（并发串台）**：
  - `SpanHandle.end()` 改为按 spanId 移除（`TraceContext.removeSpan`），不再无条件弹栈顶；
  - 新增 `telemetry/span-scope.ts`（AsyncLocalStorage，只存子代理 agentId）。`SubAgent.execute / executeCustom` 的执行体包进作用域；
    探针在作用域内产生的 chat / execute_tool span **显式指定 parent = 该子代理 invoke_agent 且不进共享栈**（`startSpan` 新增 `parentSpanId` / `detached`）；
    子代理 invoke_agent 本身的 parent 取发起方作用域（主循环 → 会话根）。chat span 由单字段改为按作用域 key 的 Map。
  - 顺带：custom 子代理的 SubagentStop 补带 `agent_id`，否则 span 配对不上、永不 end。
- **缺陷 3（chat span 不 end）**：`handleAfterModel` 的 `end()` 移入 finally，无 usage 时标 `sidcode.usage.missing`；
  AfterModel 未 fire 的悬空 span 在下一轮 BeforeModel 或 SessionEnd 时以 error + `sidcode.span.abandoned` 收掉。
- **缺陷 1（未标注）**：`SpanKind` 类型、探针订阅列表、`HookEventName` 四个成员、`perfetto.ts` 的 `TID_MAP` 四处标「预留」；
  门禁断言 4 个事件仍无 fire 方法（接线后会红，提醒同步删标注）。

## 放弃了什么（以及为什么不选）

- **缺陷 1 不做接线**（给权限检查 / hook 执行补 fire 点）：那是新功能，要确定权限确认等待的计时边界，超出本次「修错」范围；
  本次只让声明处说实话。
- **缺陷 2 不把整个 TraceContext 换成 ALS 栈**：主循环是串行的，共享栈 + 按 id 移除已经正确；全量换 ALS 要改每个 span 的产生点，
  回归面大。只在真实并发的那一层（子代理）引入 ALS，作用域只存身份不存 span，模块零依赖。
  代价：spawn 模式的子代理在独立进程里跑，其内部 span 本就不经本进程探针，不受影响。
- **缺陷 35 不在 sink 层统一包一道「出网闸」**：http / otlp 两个 exporter 的磁盘重放共用 `EventDiskCache.retryPreviousBatches`，
  闸放在这一个函数里已经覆盖全部重放路径；再加一层只是重复。
- **禁用时不删磁盘缓存**：删除不可逆，用户切回 default 后这些事件仍该补发；过期由既有 `cleanup()`（24h）处理。
