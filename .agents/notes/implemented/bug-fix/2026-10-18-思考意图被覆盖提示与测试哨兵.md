# 思考意图被模型覆盖时提示、无开关族意图粘性，以及复审遗留的注释与哨兵

## 决定了什么

对应 `20261018-思考开关修复落地复审-遗留问题清单` §5 的 PR 丁 + 戊，以及「收尾」行里不依赖真网关的 T7 + M2，合成一个 PR。

**丁（行为）**
- **R7 / R8**：新增 `App.noteThinkingIntentIfOverridden()`。用户意图为 off（`/think off`、settings `thinkingEnabled:false` 或 `SID_CODE_THINKING=off`）而当前模型 `thinkingControl` 是 `locked-on` / `none` 时，提示一次。调用点：`applyPrimaryModelSwitch`（/model、面板、降级链三条路径的汇合点）、onboarding 配置完成、TUI 就绪时（覆盖启动期 R8）、`runHeadless`（`-p` 写 stderr）。同一模型只提示一次。TUI 走历史区 hint（`appendPersistentHint`），不用状态栏瞬时提示：它几秒就消失，而「我说了关、它还在想」是用户要回头查的那条。意图本身不动。
- **判定函数与文案收口**：`thinkingIntentOverriddenNote(control, intent)`、`LOCKED_ON_NOTE`、`NO_TOGGLE_NOTE` 移到 `ui/utils/thinking-label.ts`（展示词的事实源），`think.ts` 转导出保持旧引用。
- **R9**：`/think off|on|auto` 在无开关族上也调 `setThinking` 保存意图，回执附 `NO_TOGGLE_NOTE`；与 locked-on 的意图粘性一致，切到可关模型后自动生效。无参数 `/think` 在无开关族上仍直接返回说明，不打开空面板。

**戊（注释 / 文档 / 哨兵）**
- **R4**：更正 `SendParams.thinkingIntent` 注释与 2026-10-17 fallback Note：生产中只有主循环会 fallback；未注入 getter 的旧主循环路径也会走兜底推断。
- **M1**：确认无需改码。启动、/model、恢复会话三条路径都经 `resolveCurrentModelConfig`，条目带 provider 时回写 `config.provider`，所以 `loop.ts` 取 `config.provider` 与 fallback resolver 取 `mc?.provider` 在主模型上恒等。在 `loop.ts` 写了注释。

- **T8**：在不变量测试注释里写明「锁一致不锁数据」的边界。
- **T1**：新增 `piped-stdin-release.test.ts`，子进程不调 `process.exit`，只靠 `pause()` 退出。
- **T6**：原方案 §9.3 的 8 行变异逐行实跑，结果记进对应的三份 Note。
- **M3**：原方案 §4.6 表格注明已改为 `always` / `by-model`（方案文档在仓外）。

**收尾（可在本地做的部分）**
- **T7**：新增 `packages/cli/tests/cli/print-thinking-wire-matrix.test.ts`，固化原方案 §2.2 的假上游矩阵：`-p` 真入口 × 7 个模型（Anthropic：sonnet-5 / opus-5-5 / sonnet-4-6 / opus-5-6；OpenAI：deepseek-v4-pro / glm-5.3 / kimi-k3）× off/auto，共 11 例，断言请求体的 `thinking.type`、`output_config` 有无，以及 R8 的 stderr 提示。每例一个独立假上游，避免并发时请求串到别的用例。

## 放弃了什么（以及为什么不选）

- **切模型时把 off 归正为 auto**：意图粘性是 #325 采纳的特性，清掉会让切回可关模型时 off 莫名失效。缺的只是提示。
- **提示走状态栏 `notifyStatus`**：瞬时提示 8s 消失，`-p` 下也没有。历史区 hint 能保留，不进 ctxMgr，也不发给模型。
- **on / auto 在 none 族上也算「意图被覆盖」并在切模型时提示**：状态栏已显示 `by-model`；auto 本来就是跟随模型。只有 off 是「用户以为关了实际没关」，提示要克制，否则用户会习惯性忽略。（`/think on` 在 none 族的回执仍附说明：那是用户主动操作的当下。）
- **按模型永不重复提示 vs 每次切入都提示**：选前者（复审 R7 原话「同一模型重复切入不重复提示」）。代价是来回切同一模型时第二次不提示，状态栏 `always` 警告色仍在。
- **R4 顺手让 side-call / 子代理接 fallback**：那是改变降级行为的另一件事，影响面与成本另议，不混进注释更正。
- **M1 改主循环按条目取 provider**：两者在生产中恒等，改码只会多一个分叉点。
- **M2 顺手给 `modelCompat` 加 `thinking_omit_means`**：新增用户可见配置键，要过 schema、参考页与配置文档，属于新特性，不混进修复收尾。
- **T7 共用一个假上游**：首版探针这样写，并发时每个用例都收到了别人的请求，断言 `captured[0]` 会取错。
