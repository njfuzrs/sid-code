# 终端尺寸兜底改为进程内只算一次，并自己收掉 `/dev/tty` 的 fd

## 决定了什么

`packages/tui/src/utils.ts` 的 `getWindowSize` 在 `stdout.columns`/`rows` 为 0 时（PTY 0×0、
stdout 被接管）会走兜底。此前每次调用都调 `terminal-size@4.0.1`：

- macOS 上它 `fs.openSync('/dev/tty', O_EVTONLY|O_NONBLOCK)` 之后**既不 close 也不 destroy**；
- 打不开 `/dev/tty` 时每次起两个 `tput` 子进程（`cols` + `lines`）。

这个函数在渲染路径上每帧被调多次（`ink.tsx` 十几个调用点 + `use-window-size` + `use-animation-frame`），
所以泄漏和子进程都按帧累积。实测：PTY 0×0 下 200 次调用 tty fd 从 3 涨到 205；
无控制终端时单次 2.4–3.5 ms。

改动三件事：

1. **兜底结果按进程缓存一次**（`fallbackSize ??= computeFallbackSize()`）。兜底只由进程环境
   决定（`/dev/tty` 尺寸、`COLUMNS`/`LINES`、有没有控制终端），算一次就是常量；真实 resize
   之后 `stdout.columns`/`rows` 会自己更新，走快路径，不需要让缓存失效。
2. **兜底自己实现，去掉 `terminal-size` 依赖**：保持上游的优先级（stderr → `COLUMNS`/`LINES`
   → 平台能力；darwin 先 `/dev/tty` 再 `tput`，linux 再补 `resize -u`，win32 只有 `tput`），
   但 `/dev/tty` 拿到的 fd 用完 `destroy()` 关掉，命令加 500ms `timeout`（这条路径是同步执行的，
   `tput` 卡住会挂起整个 TUI —— 上游没有这个保护）。
3. 新增 `packages/tui/tests/window-size.test.ts` 三条门禁：打开 `/dev/tty` 次数 ≤ 1、
   500 次重复调用 < 200ms、调用前后 tty fd 数不变。

`resetWindowSizeFallbackForTests()` 是给门禁用的重置入口（同一进程只算一次，跨用例换环境要先清）。

## 放弃了什么（以及为什么不选）

- **只加缓存、继续用 `terminal-size`（最小改动，约 3 行）** —— 否决。它能把「每帧泄漏」
  降成「每进程泄漏 1 个」，但泄漏本身还在，且 `tput` 无 timeout 的隐患也还在。
  缺陷文档给的验收口径是「tty fd 数不增长」，只加缓存过不了。
- **在 `ink.tsx` 里把尺寸收成实例字段、只在 resize 事件时更新（文档方向的第一条）** —— 否决。
  真正贵的只有兜底（同步 I/O / 子进程），`stdout.columns` 是普通属性读；把尺寸缓存到实例上
  要重新定义 resize、`forceRedraw`、alt-screen 三处的尺寸来源，风险远大于收益。
  本 PR 只动兜底，快路径一个字没改。
- **保留 `terminal-size` 依赖但不再 import** —— 否决，死依赖比删掉更容易误导后来的人。
- **`/dev/tty` 用 `O_RDONLY` 打开**（比 `O_EVTONLY` 好记） —— 否决，等于要求终端读权限，
  在只写终端下会失败；保持上游口径。

## 拿什么证明它生效了

探针（`getWindowSize` 真实代码，`lsof` 数 tty fd）：

- 修前 · PTY 0×0（`expect` 起子进程，未设 `stty_init`）：200 次调用 `ttyFdsBefore=3` → `ttyFdsAfter=205`；
- 修后 · 同一环境：`3` → `3`；
- 修前 · 无控制终端：`perCallMs=2.35`（每次两个 `tput`）；修后同环境重复调用只剩缓存命中。

门禁三条都做过变异自证：

| 变异 | 结果 |
| --- | --- |
| 去掉缓存（`??=` 改 `=`） | 「不再打开 /dev/tty」红（Expected 1 / Received 501）、「不再每次起 tput」红（1165ms > 200ms） |
| 去掉 `readDevTty` 的 finally 关闭 | PTY 下「fd 会被关回去」红（Expected 6 / Received 7） |
| 恢复实现 | 3 pass / 0 fail |

跑过的命令：`bun test ./packages/tui/tests/window-size.test.ts`（3 pass）+
整个 `packages/tui/tests/`（见 PR 正文）+ `make build` + `bun run affected-tests:run`。
