# 可观测性缺陷 13–20：非流式计费收口、/telemetry span 树会话内可读、JSONL 轮转口径

## 决定了什么

- **13 / 14**：main 上已不复现，本 PR 不改代码。`token-meter.ts` 在 #136（OTel GenAI 拆分 counter）时
  已改走 `normalizeCacheUsage` 取 `promptTotal`（OpenAI 族不再双计 cache_read），并发出
  `gen_ai.client.inference.usage.cache_write.input_tokens`。`tests/telemetry/hook-probe.test.ts`
  「OpenAI 族 prompt_tokens 已含命中」「拆成独立 Counter」两条已锁住。
- **15**：两个 provider 的三条非流式路径（OpenAI Chat / Responses、Anthropic）在拿到 2xx 后
  `emitHttpConnected`，finally 里调新的 `recordNonStreamingBilledRequest`（billing-sink.ts）。
  这样 `HttpConnected == BilledRequest` 恒等式在非流式上同口径成立。身份取 ALS，无身份即主循环，`accounted=true`。
- **16**：新模块 `llm/side-call-nonstreaming.ts::sendNonStreamingSideCall`：包 `withRequestContext`
  挂 querySource，并**无条件** `recordSideCall`。usage 缺失记 0 token + `usageMissing`
  （`SideCallStats.usageMissing` 新字段）。五个调用点（warmup / tool-classifier / bash-classifier /
  web-fetch-extract / title-generation）全部改走它，五个 querySource 进 `BILLING_SELF_REPORTED_LABELS`，
  消费侧因此不二次加钱。
- **17**：`TelemetryBus` 记活跃 `SpanHandle`，`getActiveSpans()` 返回快照（不进导出队列）。
  `/telemetry` 把快照并入建树，根 span 标「⋯进行中」。
- **18**：`buildSpanTree` 给孤儿（有 parentSpanId 但父不在本批）打 `orphan` 标记、计数，渲染「⊘孤儿」并汇总一行。
  `SPAN_KIND_LABELS` 类型改为 `Record<SpanKind, string>`，补齐 5 类。
- **19**：`bus.getEvictedSpanCount()` 累计 history 截断数，`/telemetry` 明说「历史已截断 N 条」。
- **20**：JSONL 导出器改**写前**检查（现有 + 本批 > 上限先轮转，空文件不轮转）。新增
  `listJsonlGenerations(dir, prefix)` 从旧到新枚举全部代。仓内两个读 `metrics.jsonl` 的脚本
  （policy-trigger-rate / event-coverage）改用它。

## 放弃了什么（以及为什么不选）

- **15 不把非流式也改成消费侧再 recordSideCall 加钱**：影子调用点已经自己 recordSideCall（带 byLabel 与失败统计），
  再由发生侧加一次就是 billing-sink 文件头写过的「双记高估」。所以发生侧事件只做核对与归因，钱仍走白名单跳过那一路。
- **16 不改成「usage 缺失就按估算 token 计价」**：估算是编出来的数，会把「不知道」伪装成「知道」。
  记 0 并加 `usageMissing` 计数，让缺口可见即可。
- **17 不把根 span 改成每轮 end/重开**：那会改变导出到 OTLP 的 span 结构（一个会话多个根），违背缺陷 2/3 修完的树形。
  只在读路径补快照，导出语义不变。
- **19 不改 history 为「按树保留」的淘汰策略**：实现复杂，且 500 条上限本身只服务交互展示；先把截断对外表达出来，
  有真实反馈再说。
- **20 不在轮转时写标记文件**：消费方要读所有代，一个枚举函数比约定标记格式简单，也不会出现标记与文件不同步。

## 拿什么证明它生效了

- `packages/core/tests/telemetry/observability-d15-d20.test.ts`（13 条）：非流式 2xx 时 BilledRequest 与 HttpConnected 各一条，
  非 2xx 两边都不记，无 usage 仍有 0 token 事件；影子调用带 caller 且 `shouldChargeBilledRequest=false`；
  无 usage 计 `usageMissing`；活跃快照 / 截断计数；JSONL 写前轮转后当前文件不超上限，三代合起来数据不丢。
- `packages/core/tests/llm/billing-self-reported-labels.test.ts` 新增两条静态门禁：`llm/` 外直调
  `sendMessageNonStreaming` 只允许 `api/stream-handler.ts`（主循环降级，已经 AfterModelRaw 入账）；
  走 helper 的 querySource 必须都在白名单里。
- `packages/cli/tests/command/telemetry-command.test.ts` 新增 3 条：进行中的根 span 能画成树、孤儿标记与计数、截断提示。
- 真实轨迹核对（合并后）：会话 `events.jsonl` 里 `caller ∈ {tool_classifier, title_generation, …}` 的 `BilledRequest`
  从 0 变成有值，digest 计费恒等式在非流式影子调用上不再是 `0 == 0`。
