# D3：停滞升级 L2 默认开启之前必须先收口的两件事（含一个已证实的误判）

## 决定了什么

评估报告 §6.2 的 D3（影子期结束后把 L2 真停默认开启）**本次不做，也不能照原条件做**。D2 把 L2 做成了「影子 + `stallHardStop` 可选真停」，缺省仍只落 `StallEscalation{level:2, acted:false}` 事件。D3 在下面两个前置条件都满足之前不许把默认值切成真停：

1. **有真实影子数据**。原条件是「D2 上线满一个版本」，现在 D2 还没发版，线上 `StallEscalation` 事件一条都没有。只有本机离线下界重放（见 `implemented/feature/2026-10-21-停滞升级阶梯L1L2影子与收尾闸门联动.md`），它不是影子期的替代品。
2. **收口已证实的误判**：本机会话 `20261016-030844-57de4f89`（模型 `origin-deepseek-v4-1-flash`，208 次 API）在 CI 等待期间约 40 次轮询 `gh pr checks` / `gh run watch`，L2 影子在第 173、193 工具轮命中。这是合法等待，不是停滞。决策 1 的要求是「抽检全部 L2 命中会话，误判为 0 才默认开」——现在已知至少 1 例，所以现状不满足。

可选的收口方向（**未选定、未实现**，需要先有影子数据再定）：

- 对「等待类」命令（`gh pr checks`、`gh run watch`、`sleep` 轮询）在空转与无改动判据里豁免；
- 或提高 L2 的确证门槛（要求更多独立确证信号，而不是 L1 后新增 1 次空转上报）；
- 无论选哪个，回归样本至少含 `57de4f89`（必须不触发 L2）和 `ce7ea52e`（必须仍触发 L2）。

## 放弃了什么（以及为什么不选）

- **现在就调阈值把 `57de4f89` 摘掉**：只有 1 个误判样本、0 个线上数据，按它调阈值是在拟合一个点；而且 CI 轮询和「停止编辑后原地空转」在可用信号上同形，小改阈值要么摘不掉它、要么连 `ce7ea52e` 一起摘掉。
- **按命令名硬编码白名单**：语义启发式，脆；且是否值得做取决于影子期里这类误判有多常见，没有分母不该先写。
- **D3 照原条件（上线满一版本）直接开**：会把已知误判直接上线成强停。

## 拿什么证明它生效了

（proposed，尚未实施。）实施时的验收：

- 影子期结束后，按 (model, 会话 API 次数分桶) 统计 `StallEscalation{level:2}` 命中，**人工抽检全部命中会话**，误判为 0；
- 回归测试固定 `57de4f89` 形态（长时间只读轮询）不触发 L2、`ce7ea52e` 形态仍触发，做变异自证；
- 默认值变更写进发版说明。
